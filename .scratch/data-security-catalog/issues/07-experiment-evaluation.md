# 07: 实现实验运行与历史信息效果评估

**What to build:** 提供可重复的实验运行器，比较完整/候选目录、批量/逐条提交和带历史/不带历史的组合效果与成本。

**Blocked by:** 04: 实现完整目录下的字段分类流水线；05: 实现候选目录召回与候选分类流水线；06: 实现独立置信度 AI 评估节点

**Status:** ready-for-agent

- [ ] 支持完整目录/候选目录、批量/逐条、带历史/不带历史三组实验变量
- [ ] 支持 8 组基础组合，并能在资源有限时先运行 4 组批量最小对照
- [ ] 每组实验固定模型、提示词、目录、表画像、字段顺序、批次边界、历史数据集、关联规则和生成参数
- [ ] 每组在金标准调优集上重复运行 3 次，并记录运行配置和重复序号
- [ ] 能计算最细目录、各级目录、敏感性准确率、敏感漏判率、Token、耗时和结果波动
- [ ] 能按同一 `field_id` 计算历史帮助、历史伤害、无影响和路径变化
- [ ] 能区分候选未召回正确路径与候选中选择错误
- [ ] 支持固定候选集的历史对照，以及历史参与召回的端到端专项实验
