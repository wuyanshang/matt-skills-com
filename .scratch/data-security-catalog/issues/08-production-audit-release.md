# 08: 实现结果审计、版本管理与生产编排

**What to build:** 将分类、置信度、兜底和实验结果串成可追溯的生产流水线，支持小批量发布、版本对比和回滚。

**Blocked by:** 04: 实现完整目录下的字段分类流水线；05: 实现候选目录召回与候选分类流水线；06: 实现独立置信度 AI 评估节点；07: 实现实验运行与历史信息效果评估

**Status:** ready-for-agent

- [ ] 每条结果能关联 `field_id`、`table_id`、`run_id` 和完整运行配置
- [ ] 保存原始字段、表画像、历史匹配、候选列表、分类输出、敏感性、置信度、重试和异常状态
- [ ] 初期生产默认采用候选目录、字段批量和置信度 AI 全量调用
- [ ] 低分、冲突、候选为空或兜底触发时走完整目录
- [ ] 模型、提示词、目录、目录语义、画像逻辑、召回规则和阈值全部版本化
- [ ] 新版本经过调优集、回归集、盲测集和小批量试运行后才能逐步放量
- [ ] 新旧版本结果并存，能够查询差异并回滚到旧版本
- [ ] 历史模式保持可切换，只有评估证明收益大于伤害且不增加敏感漏判时才设为默认
