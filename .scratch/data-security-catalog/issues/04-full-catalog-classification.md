# 04: 实现完整目录下的字段分类流水线

**What to build:** 在完整安全目录下，对字段进行批量或逐条分类，输出最细安全目录和由目录派生的敏感性。

**Blocked by:** 01: 建立安全目录主数据与路径校验；02: 实现数据字典的表级上下文与画像缓存；03: 实现历史盘点信息关联与有无历史开关

**Status:** ready-for-agent

- [ ] 分类请求包含当前字段、整表基本信息、整表完整字段清单、整表画像、可选历史参考和完整安全目录
- [ ] 支持字段批量提交和字段逐条提交两种方式
- [ ] 批量提交时每个字段独立返回结果，不因同表或同批字段强制分类一致
- [ ] 模型返回最细 `path_id`、完整路径、备选路径、证据字段和分类理由
- [ ] 程序拦截非法路径、父子层级不一致、字段遗漏、重复字段和不完整输出
- [ ] 技术性错误支持有限重试，仍失败时标记业务查看，不编造分类
- [ ] 分类通过后由目录主数据派生敏感/非敏感
