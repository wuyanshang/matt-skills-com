# 01: 建立安全目录主数据与路径校验

**What to build:** 建立附录 A 安全目录的正式主数据，使系统能够识别每个最细安全目录节点、完整层级路径和敏感性配置。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 能加载附录 A 的正式分类路径，并为每个最细节点分配稳定且唯一的 `path_id`
- [ ] 每个节点保存主题域、二级分类、三级分类、最细节点、目录定义、适用范围、排除范围、敏感性和目录版本
- [ ] 能校验 `path_id` 是否存在，以及路径各层级是否属于同一条父子链
- [ ] 能根据最终 `path_id` 返回敏感或非敏感
- [ ] 目录主数据不允许模型运行时新增、修改或覆盖
