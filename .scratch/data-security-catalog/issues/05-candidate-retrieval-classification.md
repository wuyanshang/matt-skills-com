# 05: 实现候选目录召回与候选分类流水线

**What to build:** 在不提供完整目录的情况下，由程序召回候选完整路径，再让分类模型从候选中选择最细目录，并支持兜底。

**Blocked by:** 01: 建立安全目录主数据与路径校验；02: 实现数据字典的表级上下文与画像缓存；03: 实现历史盘点信息关联与有无历史开关

**Status:** ready-for-agent

- [ ] 综合字段名称、数据资产、表名、整表画像、同表字段语义和可选历史参考召回候选
- [ ] 召回支持关键词、同义词、向量相似度和规则扩展等组合方式
- [ ] 历史信息只能影响候选排序，不能排除其他候选
- [ ] 根据字段歧义程度动态调整候选数量，并记录候选数量和召回依据
- [ ] 分类模型只接收候选完整路径，返回最细 `path_id`
- [ ] 候选为空、候选不足或触发冲突时转入完整目录兜底
- [ ] 能记录正确路径是否进入候选集合，以支持召回与选择错误拆分评估
