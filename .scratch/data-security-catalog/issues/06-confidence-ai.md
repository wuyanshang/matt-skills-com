# 06: 实现独立置信度 AI 评估节点

**What to build:** 使用独立模型检查分类结果是否有充分证据，输出业务可读的置信度分数和查看建议，但不修改分类结果。

**Blocked by:** 04: 实现完整目录下的字段分类流水线；05: 实现候选目录召回与候选分类流水线

**Status:** ready-for-agent

- [ ] 置信度 AI 与分类 AI 角色分离，优先使用不同模型
- [ ] 第一轮输入不包含分类模型理由，只包含原始证据、整表画像、历史参考、分类结果和实际目录范围
- [ ] 完整目录模式和候选目录模式使用与分类 AI 相同的目录范围
- [ ] 输出 0～100 分数、是否建议业务查看、原因和可选疑似替代路径
- [ ] 不自动重新分类、不自动修改正式 `path_id` 和敏感性
- [ ] 实验阶段支持所有字段调用，生产阶段可按风险缩小调用范围
- [ ] 记录置信度 AI 模型版本、输入输出消耗、耗时和完整意见
