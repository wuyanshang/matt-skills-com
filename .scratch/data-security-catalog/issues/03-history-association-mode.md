# 03: 实现历史盘点信息关联与有无历史开关

**What to build:** 将已有资产盘点结果作为可控的辅助参考接入分类请求，并支持严格的带历史/不带历史对照。

**Blocked by:** 02: 实现数据字典的表级上下文与画像缓存

**Status:** ready-for-agent

- [ ] 按 `field_id`、表标识加源字段英文名、表标识加源字段中文名的顺序关联历史记录
- [ ] 无法唯一匹配时标记 `ambiguous`，没有匹配时标记 `unmatched`
- [ ] 历史记录保存原始分类、数据资产、历史置信度和历史版本
- [ ] 支持 `with_history` 和 `without_history` 两种运行模式
- [ ] 不带历史模式的模型请求不包含历史字段，也不加入“无历史”的解释文字
- [ ] 历史信息只能作为辅助证据，不能限制候选范围、覆盖当前结果或成为标准答案
- [ ] 每条结果记录历史匹配状态和历史模式
