# 02: 实现数据字典的表级上下文与画像缓存

**What to build:** 将数据字典按稳定表标识分组，并为每张表生成一次可复用的业务画像，供字段分类使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 能根据系统名称、源系统名称说明和源表英文名生成稳定 `table_id`
- [ ] 同一 `table_id` 的字段能够被完整分组，不同系统的同名表不会混组
- [ ] 每张表只生成一次整表画像，并能被该表所有字段复用
- [ ] 画像包含业务对象、表用途、一行数据含义、业务阶段、数据主体、候选业务方向、推断依据、不确定点和画像置信度
- [ ] 可选生成标准化表名和字段名，但原始名称始终保留
- [ ] 表画像版本能够在表名、表说明或字段集合发生实质变化时更新
